# MForge 完整主链接通 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从唯一 Orchestrator 入口接通 Router、六类生成器、多 Agent、L0-L4 验证、教师反馈、下游供应链与 HuMU，并用真实协议上的 synthetic L3 数据证明整条工程链可运行。

**Architecture:** Orchestrator 是唯一控制面和 run store 所有者；Agent 使用 Redis request/reply，domain service 使用 gRPC。Production 缺依赖时明确失败，synthetic 只替换外部数据与重模型工件，不替换协议、状态机或业务路由。

**Tech Stack:** Python 3.12、uv、pytest、grpc.aio、protobuf、FastAPI、SQLite、Redis、LangGraph、PyTorch、RDKit、Qdrant、Docker Compose、Helm、Kubernetes。
