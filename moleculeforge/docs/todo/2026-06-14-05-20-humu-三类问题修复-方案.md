# HUMU 预训练三类问题修复方案

## 背景

代码审查发现 HUMU 预训练存在三类问题:

- **P0 采样**:`source_sample_cap=50000` 硬截断每个数据源,且 `TargetRatioMultiSourceBatchSampler` 用单调确定性游标,每个 epoch 产出逐字节相同的 batch 序列。结果:bindingdb(314万)、route(40万)、mol(285万)等大数据源绝大部分从未参与训练,100 epoch 实为重复同一批固定 batch。
- **P1 指标/划分**:`mol_self`、`protac_component_library` 的 anchor 与 positive 编码同一输入(SimCSE 式),验证时 dropout 关闭使其检索 top1 恒为 1.0,污染聚合指标;验证集用 `random_split` 全量随机切分,小目标可能近乎缺失,且可能使某 objective 全部落入验证集导致训练采样器启动即报错。
- **P2 配置/性能**:`warmup_steps` 从未被使用;`manifold.distance` 仅对 k=1 数学正确,但 curvature 在多处硬编码 1.0,改 config 会几何不自洽;`encode_batch` 逐条 Python 循环编码,GPU 利用率低。

## 已实施的修改

### P0 采样
- `configs/models/humu_pretrain.yaml`:`source_sample_cap` 与 `objective_sampling.source_cap` 置 `null`(全量加载,RAM 1.4TiB 充足)。
- `data_loader.py:TargetRatioMultiSourceBatchSampler`:新增 `seed` 参数、`epoch` 状态、`set_epoch`;`__iter__` 用 `random.Random(seed*1_000_003+epoch)` 对每个 `(objective, source)` 索引列表生成本-epoch 随机排列,游标在排列上前进,保留 `offset=cursor*world_size+rank` 的 DDP 分片。
- `pipeline.py:_set_sampler_epoch`:同时触达 `loader.batch_sampler.set_epoch`;`_prepare_distributed_loaders` 重建采样器时透传 `seed`;`create_dataloaders` 构造时传 `seed`。

### P1 指标/划分
- `data_loader.py:_stratified_train_val_split`(新增):按 `pair_type` 分层切分,保证训练子集含每个 objective;flooring 导致验证集为空时,从最大可分 pair_type 提升 1 条。替换原 `random_split`。
- `pipeline.py:_contrastive_stats`:`_DEGENERATE_RETRIEVAL_KEYS`(`mol_self`、`protac_component_library`)排除出 `retrieval_top1` 聚合,仍单独上报。

### P2
- `pipeline.py:_apply_lr_schedule`(新增)+ 训练循环接入:前 `warmup_steps` 步 lr 线性 0→base_lr 并保持 cosine 不前进,之后由 cosine 驱动。
- `pipeline.py:_validate_config`:`curvature != 1.0` 报错;`_wrap_as_module`/`_compute_losses` 改为读取 cfg 曲率(经 `_build_encoders`/`_forward_paired_batch` 透传),单一来源。
- 向量化 `encode_batch`:`LorentzAttention.forward` 新增可选 `mask`(默认 None,hfm_3d 不受影响);route 批量 stack;mol/pocket 用 padding + masked-softmax + masked-mean。逐条 `encode` 保留。

## 验证结果

- 单测:`pytest tests/unit/test_humu_training.py tests/unit/test_lorentz_manifold.py` 全部 121 通过。
- 向量化数值等价:mol/route/pocket 的 `encode_batch` 与逐条 `encode` 最大绝对误差 ≤ 5e-7(阈值 1e-5)。
- curvature 守卫:`curvature=0.5` 触发 ValueError,`1.0` 通过。
- warmup:lr 线性 7.5e-5→1.5e-4→2.25e-4→3e-4 后转 cosine。
- 采样器:`set_epoch` 使相邻 epoch batch 不同且各 epoch 可复现。
- preflight:全量数据源校验通过(mol 285万、bindingdb 314万、retropath 124万均可见)。
- CPU 冒烟:2 epoch 跑通,12 个目标损失均有限,`collapse_ratio=0`,checkpoint 正常写出。
